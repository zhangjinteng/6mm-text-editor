# 图片特效对照与补齐

对照范围为用户提供的稿定截图中的“图片特效”区域；未声称覆盖稿定所有功能或付费素材。

| 项目 | 原有实现 | 本次补齐 |
| --- | --- | --- |
| 预设选择 | 描边、阴影分散在参数页 | 热门、描边、投影、发光、酷炫分类；16 个特效预设和无特效，当前素材缩略图 |
| 描边 | 透明轮廓单层实线/虚线/点线 | 双层轮廓描边与内外颜色、粗细调整 |
| 投影 | CSS 矩形阴影 | 透明轮廓投影和三种投影组合，保留旧矩形模式 |
| 发光 | 无 | 色彩、范围、强度和四种组合预设 |
| 酷炫装饰 | 无 | 爱心、星星、光芒、彩纸；颜色、大小、数量、间距可调 |

复用独立描边层的生成与定位机制，按裁剪/蒙版后的 alpha 生成效果；主体不烘焙，效果层随缩放/旋转/翻转同步。预设不改动滤镜、蒙版、几何和素材。保存、预览、导出保留内嵌 PNG 图层；跨域读取失败时保留原有图片并提示。

验证透明边缘/孔洞/主体像素、全部预设生成、双层描边颜色、即时调整与撤销、弹窗取消、尺寸旋转同步及保存/预览/HTML 导出。
