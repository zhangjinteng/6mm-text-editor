# 图片蒙版补齐

以用户提供的稿定截图可见功能为比较范围，不推断未展示的付费素材与隐藏选项。

| 项目 | 原有 | 本次补齐 |
| --- | --- | --- |
| 分类 | 单一列表 | 基础、图形、字母、数字、笔刷 |
| 预设 | 8 种 | 62 种，另有无蒙版入口 |
| 基础形状 | 圆、椭圆、菱形、三角、六边、星形 | 圆角矩形、切角矩形、波浪、花形、不规则形 |
| 其他形状 | 无 | 爱心、拱门、盾牌、五边形、云朵、对话框、十字、票券 |
| 字母和数字 | 无 | A–Z、0–9 |
| 笔刷 | 无 | 横向、斜向、干刷、墨迹、圆斑 |
| 自定义 | 无 | 本地上传，自动识别或选择透明通道/黑白明度 |

蒙版目录、CSS 蒙版资源和轮廓生成共用同一模块。新增矢量形状为自行定义的 SVG；字形使用浏览器字体渲染。内置 SVG 预设在保存前生成 1024×1024 PNG，避免放宽编辑器对 SVG 地址的过滤；用户上传图片也统一转换为自包含 PNG，再保存到设置与文档样式。沿用预览、取消、一次撤销、侧栏即时应用、导出与保存流程，保持侧栏单滚动区。

验证覆盖：分类选择、草稿隔离、字母孔洞、描边、自动通道识别、无效上传、SVG/PNG 保存回显、导出、窄屏与原有旋转/裁剪回归。
