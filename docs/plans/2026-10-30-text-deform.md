# 文字变形扩展

保留文字设置弹窗与实时预览，弧形页扩展为变形页。预设网格分为路径排版和轮廓变形；加入方向、起点、半径、角度、宽高比例、多行策略和自定义贝塞尔控制点。

实现：新增 text-deform 模块管理版本化配置、路径几何与字形轮廓包络变换。路径使用富样式 textPath/tspan；包络使用浏览器字体轮廓的高分辨率采样及边界追踪，简化后映射为 SVG 路径，真实改变字形几何，不依赖指定字体文件。填充、描边、投影在变形后的字形轮廓上统一绘制，保留透明度。复用填充、描边、阴影层，保留原始文本编辑模型。旧 up/down 文档兼容。

步骤：1. 实现配置、预设、路径几何、富文本排版与包络；2. 接入现有渲染和序列化；3. 预设网格、参数、自定义控制点与实时预览；4. 保存、取消、撤销、复制、静态预览及视觉验证。

验证：49 项文字相关 Playwright 测试全部通过（文字变形、旧弧形、设置弹窗、描边、填充、投影、背景、字体、编辑交互、清除格式）；包含全部预设的 SVG 像素验证与半透明填充 alpha 检查。`pnpm build` 通过，保留已有包体积提示。视觉结果见 screenshots/text-deform-gallery.png 和 screenshots/text-deform-dialog.png。
