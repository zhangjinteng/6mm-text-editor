# 文字 SVG 描边实现计划

目标：普通与弧形文字统一 SVG 描边，支持 0—10px、内/中/外、尖/斜/圆角和独立显示开关。

方案：复用原文作为编辑和排版模型。普通文字按浏览器 Range 的每行富文本片段生成 SVG，保持字体、位置、换行和颜色；弧形继续使用 textPath。共用字形裁切/遮罩和 stroke-linejoin。外描边和内描边分别使用两倍宽度后排除字形内部、裁切到字形内部，居中使用原宽度。保留静态 SVG 以支持预览和导出，不依赖运行时脚本。

步骤：
1. 扩展外观描边页与持久化属性，兼容旧 CSS 数据，隐藏时保留设置。
2. 增加共享 SVG 描边与普通文字 SVG 排版，接入编辑、字体更新、复制、撤销、字体加载。
3. 扩展序列化白名单；检查保存重载及预览。
4. 运行构建、文字相关 Playwright 测试，新增位置/拐角/开关和持久化覆盖，检查截图。

验证结果：当前文字设置面板下 `pnpm exec playwright test tests/text-stroke.spec.ts --timeout=30000` 5 项全部通过；覆盖位置/拐角、富文本换行、编辑、开关、撤销、重载、复制、静态预览、旧 CSS 迁移和普通/弧形 SVG 像素边界。`pnpm build` 通过；保留既有包体积提示。新增统一文字设置面板的同时改动已接入同一 SVG 渲染模块。
